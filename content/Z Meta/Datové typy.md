- definují druh dat, který proměnná uchovává, určují povolené operace (např. sčítání čísel vs. spojování textu) a způsob, jakým počítač data ukládá v paměti

| Typ                | Popis                | Příklad hodnoty      |
| ------------------ | -------------------- | -------------------- |
| `int`              | Celé číslo           | `42`, `-7`, `0`      |
| `float` / `double` | Desetinné číslo      | `3.14`, `-0.5`       |
| `bool` (boolean)   | Logická hodnota      | `true`, `false`      |
| `char`             | Jeden znak           | `'a'`, `'Z'`, `'!'`  |
| `String`           | Řetězec znaků (text) | `"Hello"`, `"Praha"` |
