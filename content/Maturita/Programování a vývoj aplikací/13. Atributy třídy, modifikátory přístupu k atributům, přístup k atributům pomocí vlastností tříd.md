Co je C# 
- Objektově orientovaný programovací jazyk vyvinutý společností Microsoft, běžící na platformě .NET.
- Třída:
	- Můžeme si ji představit jako šablonu nebo „formičku“, podle které vznikají konkrétní objekty (instance)
	- Zatímco třída je jen kód, objekt je živá instance v paměti, kterou vytvoříme pomocí operátoru `new` a voláním konstruktoru.

### Atributy tříd
- Co jsou Atributy ?
	- základní charakteristiky objektu 
		- proměnné, které uchovávají data v objektu
		- v podstatě nějaké vlastnosti objektu
	- Definují stav objektu.
	- Každý atribut má svůj **datový typ** (např. `int`, `string`, `bool`, `decimal`) a konkrétní hodnotu. 
		- Datové typy = Používáme základní typy (čísla, logické hodnoty `true`/`false`, řetězce jako pole znaků) nebo vlastní datové typy (třídy)
			-  Pokud máme třídu `Osoba`, můžeme vytvořit proměnnou typu `Osoba`.
	- **Skládání**: Objekty mohou být složené z jiných objektů. Například třída `Úsečka` může mít jako atributy dva body, přičemž `Bod` je samostatná třída se souřadnicemi `x` a `y`.
	- **Statické atributy** 
		- Pomocí klíčového slova `static` definujeme atribut, který patří celé třídě, nikoliv konkrétní instanci. 
		- Všechny objekty dané třídy sdílejí jednu a tu samou hodnotu tohoto atributu.

### Modifikátory přístupu
Co je **modifikátor** ?
- Určují kdo a odkud může k atributům (nebo metodám) přistupovat
- klíčový prvek bezpečnosti kódu.
- Druhy modifikátorů:
	- `Public`: Atribut je viditelný úplně všude, i mimo vlastní třídu. Každá jiná třída může tento atribut číst nebo měnit.
	- `Private`: Nejpřísnější úroveň. Atribut je viditelný pouze uvnitř třídy, kde byl definován. Modifikace je možná pouze metodami dané třídy.
	- `Protected`: Atribut je přístupný uvnitř třídy a také ve všech třídách, které z původní třídy dědí.
	- `Internal`: Přístup je omezen na aktuální projekt (sestavení).
	- `Protected internal`: Kombinace, kdy je člen přístupný v rámci celého projektu nebo v odvozených třídách v jiných projektech.

### Zapouzdření a vlastnosti (properties)
- **Zapouzdření**
	- jeden ze základních pilířů OOP
	- FUNKCE
		- skrývá vnitřní implementaci objektu a vystavuje pouze nezbytné rozhraní.
		-  Zajišťuje integritu dat a umožňuje snadnější údržbu kódu.
	- princip, kdy data (atributy) skrýváme před přímým přístupem zvenčí a umožňujeme s nimi manipulovat pouze kontrolovaně
		- k této manipulaci se používají **vlastnosti** (properties)
- **Vlastnost**
	- Vlastnost je v podstatě „brána“ k privátnímu atributu.
	- skládá se ze dvou částí:
		- Getter (`get`) - funkce, která získá hodnotu atributu a vrátí ji
		- Setter (`set`) - procedura, která nastavuje hodnotu atributu, a sama nic nevrací. Používá klíčové slovo `value`, které reprezentuje hodnotu, kterou se snažíme do atributu přidat.
	- pokud jednu ze 2 částí vynecháme, vytvoříme vlastnost pouze pro čtení (`read-only`) nebo pouze (`write-only`)
	- V moderním C# můžeme používat Automatické vlastnosti , kde za nás kompilátor vytvoří skrytý privátní atribut sám.
```C#
	class Osoba 
	{ 
		private string jmeno; // privátní atribut
		public string Jmeno
		{ 
			get { return jmeno; } // getter vrací hodnotu 
			set { jmeno = value; } // setter nastavuje hodnotu 
		}
	}
```

### Metody tříd

Metody jsou bloky kódu určené k vykonávání konkrétního úkolu. Zjednodušují a zpřehledňují kód. Název metody bývá tvořen jako její účel v rozkazovacím způsobu.

- **Procedura (void)**: Nic nevrací, pouze vykoná operaci (např. výpis na konzoli).
- **Funkce**: Po vykonání vrací svůj návratový typ (proměnnou, pole či objekt).
- **Parametrické metody**: Při volání vyžadují vstupní parametry.
- **Přetížené metody**: Více metod se stejným názvem, ale odlišnými parametry (typem nebo počtem).
- **Statické metody**: Metody označené static, které lze volat bez vytvoření instance třídy. Třída obsahující pouze statické metody se nazývá Knihovní třída .

### Typické otázky u maturity

- **Jaký je rozdíl mezi atributem a vlastností?** Atribut je datové pole v paměti, vlastnost je rozhraní (get/set) pro bezpečný přístup k němu.
- **Proč používáme modifikátor private?** Kvůli zapouzdření, abychom měli kontrolu nad integritou dat a zabránili nechtěným změnám zvenčí.
- **Co je to void?** Klíčové slovo označující prázdný návratový typ, tedy metodu, která nic nevrací (proceduru).
- **Kdy použijeme this?** Při odlišení atributu třídy od parametru metody se stejným názvem.
- **Co je to Messenger?** Objekt sloužící jako přepravka pro přenos více datových hodnot mezi třídami.
