# HTML
- Hyper Text Markup Language
- Standardní značkovací jazyk pro tvorbu dokumentů v prostředí World Wide Web (webových stránek), definující strukturu obsahu pomocí elementů
-  slouží k propojení dokumentů pomocí hypertextových odkazů a dnes dominuje celému internetu (tvoří kostru většiny webových stránek).
- Klient-server architektura
- další jazyky spojené s HTML jsou 
	- **CSS** - vizuální podoba
	- **JavaScript** - interaktivita
	- **PHP** - jazyk běžící na straně serveru (generování dynamického obsahu)
- Jazyk vznikl v roce 1990 v CERNu *(Evropská organizace pro jaderný výzkum)*, protože tehdejší systémy (TeX, SGML) byly pro potřeby vědců příliš složité a nepraktické
- aktuální verze HTML5
	- přinesla sémantické značky (např.`<article>`, `<section>`) a nativní podporu pro multimédia bez nutnosti pluginů.

- ### Jak Html Funguje ?
	- nejedná se o programovací jazyk ale **značkovací jazyk**
		- Používá tzv. tagy (značky) zapsané ve špičatých závorkách, které prohlížeči říkají, jak má daný obsah interpretovat.
	- Co není tag, to se zobrazí jako prostý text (plaintext)
	- HTML není citlivé na velikost písmen (case sensitive)
	- délkové jednotky v HTML (pixely, procenta, stupně písma, pc, cm)
	- ##### HTML tagy (značky)
		- Tagy určují, jak bude text vypadat, tedy jakou bude mít formu
		- tagy se vždy nachází v ostrých závorkách `<Tag>`
		- tagy můžeme dělit na 2 skupiny:
			- **Párové**
				- začátek a konec 
				- `<h1> Nějaký text </h1>`
			- **Nepárové**
				- pouze jeden tag, který nemá dvojici
				-  `<img>, <br/>`
				- U nepárových tagů ve verzi HTML5 lomítko na konci být může ale nemusí.
		- Základní příklady tagů:
			- `<h1> </h1> - <h6> </h6>` (vymezení nadpísů)
			- `<p> <p/>` (vymezení odstavce)
			- `<b> <b/>` (tučný text)
			- `<span> <span/>` (jako div, ale pro inline text)
			- `<div> </div>` (odděluje sekci stránky, primárně na práci s CSS)
			- `<br>` (zalomení řádku)
			- `<img>` (vložení obrázků)

	- ##### Atributy
		- Rozšiřují vlastnosti tagů, zapisují se do otevírací značky ve formátu `název="hodnota"`, např. `<a href="url">`.

	- ##### Formuláře v HTML
		- obaluje tag `<form>`
		- atributy
		    - `action` - akce na vykonání, kam má výsledek být poslán na vyhodnocení
		    - `method` - HTTP metoda - GET či POST, nebo jiné ale tohle je main
		- vstupní pole - `<input>`
		    - typy - text, password, submit, checkbox, radio
		    - html5 typy - email, date, number
		        - přinášejí automatickou validaci vstupu na klientské straně, web to uživatele nenechá odeslat
	- #### Struktura HTML
```
	<!DOCTYPE html>
	<html>
	  <head>
	    <meta charset="UTF-8">
	    
	    <title>Má první stránka</title>
	    
	    <style> 
	    body { background-color: lightblue; } 
	    h1 { color: navy; } 
	    </style>
	    
	  </head>
 
	  <body>
	    Moje první html stránka.
	    A nějaké další texty.
	  </body>
	</html>
```
	
		- 

- Každý HTML soubor má svou pevnou hierarchii, bez které by prohlížeč nevěděl, jak stránku vykreslit.
- **sekce**:
	- `<!DOCTYPE html>` (deklarace že se jedná o HTML stránku)
	- `<html> </html>` (Hlavní obal celého dokumentu, bez něj kód nefunguje.)
	- ==Meta Tagy==
		- Definují metadata HTML dokumentu
		- Metadata nejsou zobrazena na stránce
		- `<meta charset="utf-8">`: Nastavení kódování znaků, aby fungovala čeština (diakritika).
		- `<meta name="description" content="Popis obsahu webové stránky"> `
		- `<meta name="keywords" content="HTML, CSS, JavaScript"> <meta name="author" content="John Doe">`
		- `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
	- `<style></style>`: Prostor pro vkládání CSS stylů.
	- `<body></body>`: Zde je veškerý viditelný obsah stránky (texty, tabulky, obrázky, formuláře).
		- Do body pro přehlednost většinou vkládáme Javascript kód, který se řídí posloupností (od shora dolů)
- Pro úpravu vzhledu se dnes téměř výhradně používá CSS, které odděluje obsah od vizuální podoby.
- HTML se často kombinuje s JavaScriptem pro interaktivitu nebo s PHP na straně serveru.

- #### Viewport
	- Prohlížeč na mobilních zařízení stránku zmenšuje, aby se na display vešla celé
	- Většina webů je ale navržená tak, aby byla responzivní a je nežádoucí, aby prohlížeč měnil velikost, proto využijeme **viewport**
	- **Definuje viditelnou oblast:** Na mobilních zařízeních se obsah často nevejde celý, proto viewport určuje, jak velká část stránky je "vidět".
		Pomocí HTML `<meta>` tagu:
	`<meta name="viewport" content="width=device-width,initial-scale=1">`
		říkáte prohlížeči, aby přizpůsobil šířku stránky šířce displeje zařízení, místo aby ji zobrazil v plné desktopové šířce a zmenšil ji.
	

### SEO
- (Search Engine Optimization)
- Optimalizace vyhledavače/náleznosti
- metodika vytváření a upravování webových stránek takovým způsobem, aby jejich forma a obsah byly vhodné pro automatizované zpracování v internetových vyhledávačích
- cílem SEO je získat ve výsledcích vyhledávání lepší pozici (odkaz na stránky bude zobrazen mezi prvními), a tím i četnější a zároveň cílené návštěvníky
