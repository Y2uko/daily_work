
## CSS
- CSS (Cascading Style Sheets)
- programovací jazyk používaný k definování vzhledu, rozložení a grafické úpravy webových stránek napsaných v HTML nebo XML
	- hlavní aspekty:
		- vzhled a design
		- rozložení (Layout)
		- responzivita
		- oddělení vzhledu od obsahu webu (Jeden CSS soubor mimo hlavní kód může stylovat celý web, což usnadňuje údržbu)
- Spolu s HTML a Javascriptem patří mezi hlavní způsoby psaní stránek (svatá trojice)
- CSS umožnuje rozdělení rozložení stránky (HTML) a jeho prezentací (CSS)
	- rozdělení stylu prezentace pro rozdílné zařízení
	- použití jednoho souboru stylů pro několik stránek (urychlení načítání stránky když je CSS cached
- **Cascading** ve jméně znamená řetězení/kaskádování stylů
	- pokud má jeden element upravované nějaké hodnoty na více místech (třeba víckrát margin:” ”) CSS vždy stejně vybere, který má přednost
		1. důležitost (přebíjí všechny ostatní) - **!important** (příkaz pro vynucení priority)
		2. původ - styl autora -> styl definovaný autorem stránky -> defaultní styl prohlížeče
		3. selektor - id -> class -> tag (vybírá, pro jakou část markupu styl platí)
		4. podle posloupnosti v kódu (pokud mají stejnou úroveň platí to co je dříve zapsáno v kódu)
- syntaxe používá anglická klíčová slova

- ### Jednotky a responzivita
	- Při psaní stylů musíme pracovat s číselnými hodnotami a jednotkami. Pro moderní "mobile-first" weby je klíčové používat relativní jednotky, aby se layout pružně přizpůsobil velikosti displeje:
		- **px (pixely)**: Absolutní jednotka. Na všech zařízeních má stejnou velikost, což může na malých displejích rozbít layout.
		- **vw/vh**: Relativní jednotky odvozené od šířky (viewport width) nebo výšky (viewport height) displeje.
		- **% (procenta)**: Relativní hodnota vzhledem k rozměrům rodičovského elementu, ve kterém je prvek vložen.
		- **rem**: Relativní jednotka odvozená od velikosti písma nastavené v kořenovém elementu (`<html>`). Je ideální pro přístupnost webu, protože respektuje nastavení prohlížeče uživatele.
		
- ### Typy zápisů CSS
	- rozdělujeme na 3 základní, kterými můžeme vložit stylování do HTML dokumentu
		- ==Přímý styl=
			- CSS se píše k jednotlivým elementům pomocí atributu  `style=""`
			- ve větších webech je zápis velmi nepřehledný
			- hodí se naopak pro rychlou úpravu jednoho konkrétního prvku kde se nevyplatí tvorba třídy
			- příklad:    `<div style="text-align: left;">Ukázka</div> `

		- ==Interní stylesheet==
			- CSS kód je umístěn přímo v HTML souboru, ale odděleně v sekci `<head>` uvnitř párového tagu `<style>`
			- ideální pro menší weby či jednostranné weby (one-page)

		- ==externí stylesheet==
			- CSS kód je v samostatném souboru (s příponou .css), který se k HTML dokumentu připojí pomocí tagu `<link>`
			- Nejčastější pro velké weby
			- styl takto také může fungovat pro více stránek a nemusí se ke každé dělat zvlášť

	- #### Srovnání metod zápisu

| Metoda  | Umístění               | Vhodnost                         |
| ------- | ---------------------- | -------------------------------- |
| Inline  | Přímo v tagu           | Výjimečné případy, jeden element |
| Interní | `<style>` v `<head>`   | Malé projekty, one-page weby     |
| Externí | Samostatný .css soubor | Standard pro rozsáhlé weby       |

- ### CSS Anatomie
	- skládá se ze **selektoru** a **bloku deklarací**
		- Selektor - na které elementy se styl aplikuje (např. `body`, `.trida`, `#id`
		- Blok deklarací - je uzavřen ve složených závorkách a obsahuje vlastnosti a jejich hodnoty.
*Příklad*
```
	 body { 
		background-color: white; 
		color: black;
		padding: 10px !important;
		  }
```

- ### Selektory 
	- Selektory vybírají určitou skupinu prvků v DOMu a dovolí ji stylovat.

- ##### základní typy selektorů:
	- **Univerzální** (`*`)
		- _Příklad:_ `* { box-sizing: border-box; }`
	- **Typový** (Element)
		- _Příklad:_ `p { color: blue; }` (všechny odstavce budou modré)
	- **Třídy** (`.class`)
		- _Příklad:_ `.tlacitko { background: red; }`
	- **ID**  (`#id`)
		- _Příklad:_ `#hlavicka { height: 100px; }`

	- **💡 Malá mnemotechnická pomůcka:**

		- **`*`** = **Všichni** (Anarchie – platí to pro každého).
    
		- **`p`** = **Profese** (Všichni pekaři/odstavci nosí stejnou uniformu).
    
		- **`.tlacitko`** = **Klubová karta** (Kdo ji má v kapse, patří do skupiny).
    
		- **`#hlavicka`** = **Rodné číslo** (Má ho jen jeden konkrétní člověk/prvek).

| **Selektor**            | **Co přesně dělá?**                                                     | **Vizuální dopad**                                                                                 |
| ----------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **`*`** (Univerzální)   | „Všichni v domě poslouchejte.“                                          | Nastaví všem prvkům stejný způsob počítání velikosti (`border-box`), aby se nám design nerozpadal. |
| **`p`** (Typový)        | „Všechny odstavce, oblečte si modrou.“                                  | Každý text uvnitř tagu `<p>` se zbarví modře.                                                      |
| **`.tlacitko`** (Třída) | „Kdo má na sobě dres 'tlacitko', bude mít červené pozadí.“              | Můžeš mít 10 tlačítek a všechna budou červená najednou.                                            |
| `#hlavicka` (ID)        | „Ty tam, ty jsi jediný unikátní objekt 'hlavicka', budeš vysoký 100px.“ | Cílí na jeden konkrétní prvek. Nikdo jiný nesmí mít stejné ID.                                     |

- ##### Pseudotřídy
	- Tyto selektory vybírají element pouze v určitém **stavu**.
	- přidávají interaktivitu. Například `:hover` změní vzhled elementu pouze ve chvíli, kdy na něj uživatel najede myší.
*Příklad*
```
	/* Tlačítko změní barvu, jen když na něj najedeš myší */
	
.tlacitko:hover {
  background-color: blue;
  cursor: pointer;
}

```

- ##### Pseudo elementy 
	- Tyto selektory vytvářejí "virtuální" prvky uvnitř vybraného elementu nebo stylují jeho **část**.
	- Umožňují stylovat specifické části elementu, například vložit obsah před nebo za text elementu bez nutnosti měnit HTML.
	- Používají se dvě dvojtečky `::` (v moderním CSS) a vyžadují vlastnost `content`.
*Příklad*
```
/* Přidá text "Pozor: " před každý odstavec s třídou varovani */

.varovani::before {
  content: "⚠ POZOR: ";
  font-weight: bold;
  color: red;
}

```


- #### Kombinátory
	- **Selektor potomka (mezera):** Vybere jakýkoliv element uvnitř jiného elementu (i hluboko zanořený).
	    - _Příklad:_ `div p` vybere všechny odstavce v divu.
        
	- **Selektor dítěte (`>`):** Vybere pouze ty elementy, které jsou o jednu úroveň níž (přímí potomci).
	    - _Příklad:_ `ul > li` vybere odrážky, ale ne ty, které by byly vnořené v dalším seznamu uvnitř.
        
	- **Sousední selektor (`+`):** Vybere prvek, který následuje **ihned** po určeném prvku a má stejného rodiče.
    
	- **Obecný sourozenecký selektor (`~`):** Vybere **všechny** prvky, které následují po určeném prvku a mají stejného rodiče.

| **Kombinátor** | **Název**      | **Jak to funguje (Příklad)**                   | **Výsledek v našem HTML**                                                        |
| -------------- | -------------- | ---------------------------------------------- | -------------------------------------------------------------------------------- |
| **Mezera**     | **Potomek**    | `div p { color: green; }`                      | **Zelení budou oba odstavce.** Je jedno, jak hluboko jsou schovaní.              |
| **`>`**        | **Dítě**       | `div > p { color: red; }`                      | **Červený bude jen syn.** Vnuk zůstane černý, protože je schovaný v `section`.   |
| **`+`**        | **Soused**     | `.starsi-bracha + span { font-weight: bold; }` | **Tučný bude jen Mladší brácha.** Bere to jen toho, kdo stojí _hned_ za ním.     |
| **`~`**        | **Sourozenec** | `.starsi-bracha ~ span { color: blue; }`       | **Modří budou oba mladší bratři.** Vybere to všechny sourozence, co jdou po něm. |

**Pozor:** Selektory v CSS umí koukat jenom **směrem dolů** (na děti) nebo **směrem doprava** (na mladší sourozence). Neumí vybrat „rodiče“ nebo „staršího bráchu“ (toho, co je v kódu nad ním).

- ### Důležité CSS vlastnosti (deklarace)
	- CSS nabízí obrovské množství vlastností pro úpravu vzhledu. Mezi ty nejčastější patří:

		- **Fonty**: `font-family` (typ písma), `font-size` (velikost), `font-style` (kurzíva, tučné písmo).
		- **Text**: `text-align` (zarovnání: left, right, center, justify).
		- **Barvy**: `color` (barva textu) a `background-color` (barva pozadí). Barvy lze definovat názvem, hexadecimálně (`#ff0000`), nebo pomocí `rgb`/`rgba` (kde `a` znamená Alfa kanál).
		- **Pozadí**: `background-image` umožňuje vložit obrázek na pozadí elementu pomocí cesty `url()`.
		- **Box model**: `margin` (vnější okraj), `padding` (vnitřní výplň), `border` (rámeček).
		- **Layout**: Flexbox a CSS Grid
		- **Ostatní**: `overflow` určuje, co se stane, když obsah přeteče nastavené rozměry (např. přidá posuvníky), `box-shadow` přidává stínování prvků.


# Typické otázky u maturity

**1. Jaký je hlavní rozdíl mezi HTML a CSS?** HTML definuje strukturu a sémantický obsah stránky (co tam je), zatímco CSS definuje vizuální prezentaci a rozvržení (jak to vypadá).

**2. Proč je lepší používat externí CSS soubor než inline styly?** Externí soubor umožňuje oddělit obsah od vzhledu, zlepšuje přehlednost kódu, zrychluje načítání (díky Cachování) a umožňuje snadnou změnu vzhledu celého webu úpravou jednoho souboru.

**3. Co znamená, že jsou styly "kaskádové"?** Znamená to, že se styly dědí z rodičovských elementů na potomky a zároveň se aplikují pravidla podle priority (kaskády). Pokud definujeme styl pro `body`, zdědí ho vše uvnitř, pokud není přebit specifičtějším pravidlem.

**4. K čemu slouží jednotka `px` a proč se u responsivních webů doporučuje spíše `%` nebo `vw`?** `px` je absolutní jednotka, která na všech zařízeních vypadá stejně. Relativní jednotky jako `%` nebo `vw` se přizpůsobují velikosti okna prohlížeče, což je nezbytné pro správné zobrazení na mobilech a tabletech.

**5. Jaký je rozdíl mezi selektorem třídy (`.`) a ID (`#`)?** Třídu (`.`) můžeme použít pro libovolný počet elementů na stránce. ID (`#`) musí být v rámci celého HTML dokumentu unikátní a používá se pro identifikaci konkrétního, jedinečného prvku.

Poznámka pro maturitu: Nezapomeň, že CSS je o experimentování. U zkoušky je dobré vědět, že existují i pokročilé techniky jako Flexbox nebo Grid, které dnes řeší moderní layouty mnohem efektivněji než staré plovoucí prvky (float), i když v základních zápiscích nejsou.
