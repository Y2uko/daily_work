- Dynamické webové stránky se vytvářejí až v okamžiku kdy si je uživatel otevře
	- Server při každém požadavku zpracuje data (často z **[[8. Databáze]]**), a teprve poté vygeneruje výslednou **HTML** stránku
	- Dynamický web tak může zobrazovat rozdílný obsah různým uživatelům podle jejich přihlášení, nastavení nebo aktuální situace
		- *Příklad:*  e-shop zobrazí přihlášenému zákazníkovi jeho objednávky a uložený košík, zatímco nepřihlášený návštěvník uvidí pouze veřejnou nabídku produktů.
- zpracovávají se na straně serveru
- Jednoduchý popis jak takový web funguje
	- server na rozdíl od statického neodesílá hotový soubor, nejprve zpracuje požadavek  (práce s databází, kontrola oprávnění)
	- příklad typického průběhu:
		- uživatel odešle požadavek na [URL](https://www.webglobe.cz/poradna/co-je-url)
		- server spustí aplikační logiku
		- aplikace načte data z databáze
		- vytvoří se HTML stránka
		- stránka je odeslána prohlížeči

	- jsou vhodné pro weby kde je nutná interaktivita nebo práce s daty uživatele

		- rezervační systémy
		- weby s uživatelskými účty

- ### Architektura Model View Controller ASP.NET
	-  návrhový vzor rozděluje aplikaci do tří nezávislých komponent, čímž odděluje logiku od výstupu a zpřehledňuje kód. Dnes je postupně nahrazován modernějším **ASP.NET Core**, který je plně multiplatformní.
	
	- **Model**
		- pracuje s databází
		- zpracovává veškerou logiku

	- **View**
		- Má HTML šablony na prezentování dat
		- vyplňuje HTML šablony a posílá je controlleru

	- **Controller**
		- ovládá celý request
		- na základě requestu získává data z daného **modelu** a data posílá na daný **view** aby vygeneroval prezentaci dat (html stránku) a tu navrací uživateli
		- Zprostředkovává komunikaci mezi Modelem a View
- ### Vytváření obsahu
	- #### Client-side
		- Skriptování na straně klienta probíhá přímo ve webovém prohlížeči uživatele (**klienta**)
		- Skripty jsou odeslány ze serveru a vykonány až v prohlížeči
		- používá se pro interaktivitu (animace, vyskakovací okna)
		- programovací jazyk (Javascript)
		- *Příklad:* Kliknutí na "To se mi líbí", které okamžitě změní barvu ikony bez pře načtení stránky.
	- #### Server-side
		- Skriptování na straně serveru probíhá na webovém serveru
		- Když uživatel požádá o stránku, server spustí skript, který vygeneruje HTML kód, ten následně odešle do prohlížeče
		- používá se pro:
			- přístup k databázím
			- autentizaci uživatele (přihlášení)
			- generování personalizovaného obsahu
			- zpracovávání formuláře
		- jazyky (PHP, Python, Ruby, Java, ASP.NET, Node.js)
		- *Příklad:* E-shop, který zobrazuje produkty z databáze na základě vyhledávání uživatele
	- #### Kombinování stran Client a Server
		- AJAX (Asynchronous JavaScript and XML)
			- klíčová technologie, která propojuje oba světy.
			- je klíčová technologie, která propojuje oba světy. Umožňuje klientskému Javascriptu poslat požadavek na server a získat data na pozadí, aniž by se musela celá stránka znovu načíst.

- ==Proč je databáze u dynamických stránek klíčová?==
	- umožňuje efektivní správu obsahu
	- Místo vytváření tisíců statických souborů se obsah generuje dynamicky na základě dat uložených v tabulkách
	- PHP skript při každém zobrazení stránky vytáhne správný záznam podle ID v URL adrese a vloží jej do šablony.

## Webové vs. Nativní aplikace
- Při vývoji se často volí mezi hybridním a nativním přístupem v závislosti na rozpočtu a požadavcích na výkon.

	- **Hybridní programy:** V podstatě webová stránka zabalená do „obalu“ aplikace. Uživatel často nepozná, že pracuje s webovou technologií. Využívají JavaScript, HTML a CSS. Jsou levnější na vývoj, protože jsou použitelné pro všechny systémy bez nutnosti přepisování kódu.

	- **Nativní programy:** Jsou určené pouze pro jedno prostředí či operační systém. Na jiných systémech je lze spustit jen s pomocí emulátorů. Jsou výkonnější a mají přímý přístup k hardwaru, ale jejich vývoj je nákladnější.


# Typické otázky u maturity

 **Otázka: Jaký je hlavní rozdíl mezi statickou a dynamickou stránkou?**
- Statická stránka je neměnný soubor (HTML/CSS), který server pouze odesílá prohlížeči. Dynamická stránka se generuje na serveru při každém požadavku a její obsah se mění podle uživatele nebo databáze.

 **Otázka: Co je to SQL injection a jak se jí bránit?**
- Je to útok, kdy útočník vkládá škodlivé SQL příkazy do vstupních polí aplikace. Bráníme se používáním „prepared statements“ (připravených dotazů), které vstup od uživatele správně ošetří.

 **Otázka: Proč se používá návrhový vzor MVC?**
- Aby se oddělila logika aplikace (Model) od vzhledu (View). Zvyšuje to přehlednost, usnadňuje údržbu kódu a umožňuje efektivní spolupráci více programátorů na jednom projektu.

 **Otázka: Co znamená, že je PHP "server-side" jazyk?**
- Kód se vykoná na serveru, kde se z něj vygeneruje čisté HTML, které se následně odešle do prohlížeče. Uživatel tedy nikdy nevidí zdrojový kód PHP, pouze výsledný výstup.

 **Otázka: Jaký je rozdíl mezi nativní a hybridní aplikací?**
- Nativní aplikace je určena pro konkrétní OS (např. Android/iOS), je výkonná, ale drahá na vývoj. Hybridní aplikace je web v obalu, je levnější a přenositelná, ale může mít omezený přístup k hardwaru telefonu.
