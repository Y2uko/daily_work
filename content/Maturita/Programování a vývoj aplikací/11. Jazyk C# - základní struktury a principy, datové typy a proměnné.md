- moderní, [[typově bezpečný]] a objektově orientovaný jazyk vyvinutý společností Microsoft.
- vznikl z jazyků Java a C++
- Běží na platformě .NET (poskytuje obrovské množství předpřipravených knihoven pro práci se soubory, síťovou komunikací, databázemi i uživatelským rozhraním).
- ##### Princip 
	- staví na principech objektově orientovaného programování (OOP), přičemž klade důraz na přehlednost, flexibilitu a vysoký výkon
	- OOP
		- třídy a objekty
		- dědičnost
			- V C# neexistuje vícenásobná dědičnost (*každá třída může dědit pouze od jedné třídy*)
		- zapouzdření 
		- polymorfismus
- využívá se s platformou NET Framework (*bezplatná open-source platforma pro vývojáře od společnosti Microsoft určená k vytváření, spouštění a nasazování různých aplikací*), který umožňuje spouštění aplikací na více platformách, včetně Windows, macOS a Linux
-  rozlišuje velikost písmen (tzv. case sensitive).
- neexistují globální **Proměnné** a **Metody**, vše musí být uvnitř Tříd
- používá CTS (common type system)
	-  **CTS**
		- Unifikovaný typový systém, používaný všemi jazyky pod .NET Framework
		- Všechny typy jsou potomky třídy System.Object a dědí od ní i všechny její metody
		- Všechny typy v .NET jsou buď typy hodnot nebo typy odkazů.

 
## Základní struktura jazyka Csharp

- program se dělí do hierarchie
	- zajištuje přehlednost a integritu kódu
- Základní prvky:
	- **Name space**
		- celý obal kódu, ve kterém se nacházejí třídy
		- stará se o to aby třidy nejmenovaly stejně, aby byl pořádek v kódu
	- **Třída** (class)
		- základní stavební blok programu
		- jedná se o šablonu odrážející realitu (abstraktní a reálnou)
		- šablona objektů 
		- Třída `Clovek` (definuj jméno, rodné číslo, email)
		- z jedné třídy jde udělat libovolný počet instancí (objektů)
		- třída obsahuje:
			- datové položky 
			- vlastnosti (properties)
			- metody (methods)
			- události (events)
	- **Metoda** (method)
		- část kódu vykonávající určitou činnost
		- mohou obsahovat **vstupní parametry** a **výstupní hodnotu**
		- příklad metody:
			`public bool Exists (string path)  { vlastní kód metody }`
			- metoda má vstupní parametr path (název souboru) a logickou hodnotu typu `bool` (Boolean), což znamená ano pokud soubor existuje, a ne pokud neexistuje. 
		- mohou být jak `public` tak `private`
		- ![[Pasted image 20260522125912.png|484]]
		- metody můžeme dělit na ==Funkce== a ==Procedury==
			- Funkce 
				- něco vrací (nějakou hodnotu)
				- pomocí příkazu `return` 
			- Procedura
				- nemá návratový typ, pouze vykoná kód
				- nic nevrací vyznačuje se příkazem `void` místo datového typu zapsaného při tvoření metody
	- **Objekt** (object)
		- konkrétní objekt reálného světa
		- Objekt: `Osoba` (Karel, 720316/3178, karel@gmail.com)
			- jedná se o instanci třídy `Clovek`, od které dědí
		- vzniká pomocí operátoru `new`, který zavolá konstruktor a alokuje paměť Heap

## Datové typy a proměnné 

- ### proměnné
	- (`Variable`)
	- obecný šuplík v paměti kam ukládáme data
	- nemůžeme mít v programu 2 proměnné se stejným jménem (i kdyby byly jiný datový typ)
	- má svůj **název** a **datový typ**
		- Datový typ - Určuje, co všechno může proměnná obsahovat (např. zda jde o celé číslo \(x = 5\), text nebo logickou hodnotu).
	- Konstanta = speciální typ proměnné, kdy po naplnění hodnotou již hodnotu nelze změnit
		- Příklad
			- `public const double Pi = 3.14159;`
			- `public const int DnyVTydnu = 7;`
- #### Modifikátory přístupu
	- proměnné i metody mohou mít omezený přístup
		- to se dělá pomocí příkazů:
			- `public` (veřejné)
			- `private` (soukromé)
			- `protected` (přístupné pouze v dědičnosti)
			- `internal` (přístup v rámci assembly)

- ### Datové typy
	- určují, jaký druh dat budeme v **proměnné** uchovávat
	- dělí se na:
		- **Ordinální** (hodnotové)
			- mají lineárně uspořádanou množinu prvků (1, 2, 3, 4...)
			- uloženy na **Stack** (Zásobník) = Paměťová oblast pro ukládání lokálních proměnných a volání metod
				- `bool` - logický typ (true/false)
				- `byte`, `int`, `long` - celočíselné typy (8, 32, 64 bitů)
				- `char` - jeden znak v kódování [[Unicode]]
				- `enum` - výčtový typ, definujeme si vlastní množinu hodnot 
					- *Příklad* `enum Smer { nahoru, dolu, doleva, doprava };`
		- **Neordinální**
			- hodnoty nelze jednoznačně seřadit do konečné posloupnosti a očíslovat (není zde předchůdce a následovník jako u celých čísel)
				- `double`, `float`, `decimal` - (Reálná čísla), jsou zde desetinná čísla: 2,45
				- `string` - referenční datový typ ( podstatě pole znaků), můžeme do něj vložit jakékoliv slovo třeba (Jméno, název atd..)
				
		- **Prázdný** datový typ
			- `void` - prázdný datový typ, využíván u **Procedury**
		
		- **složené** datové typy
			- Obsahují více prvků většinou stejného typu
				- `array` (pole)
					- obsahuje několik hodnot stejného typu
						- `int[]`, `string []`
						- každá položka má v poli **index** (pořadí položky), začíná se od 0
						- **matice** (více rozměrové pole(2D, 3D))
				- `string` (textový řetězec)
					- pole znaků
					- ukládá například slovo či větu
				- `list` (seznam)
					- něco jako pole
					- nelze seznam adresovat pomocí indexu ale lze ho procházet pouze postupně (od začátku do konce)
					- + výhoda (snadné přidávání a odebírání prvků uprostřed)
