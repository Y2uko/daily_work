- Co a k čemu je konstruktor ? 
	- Speciální **metoda** třídy v OOP
	- Automaticky se spouští při vytvoření nové instance (objektu) dané třídy, je volán operátorem `new`
	- inicializuje třídu
	    - přiřazuje hodnoty atributům
```
public class Person { 
   private String name;
   private int age; 
   // konstruktor se dvěma parametry 
   // - inicializuje hodnoty proměnných ve vytvořeném objektu 
   public Person(String n, int a) { 
      name = n;
      age = a;
   }
}
```

- využití - Clovek Karel = new Karel("Karel z Hongkongu, 79)

**Konstruktor**
- má vždy stejný název jako třída, do které patří
- nemá žádný návratový typ (ani `void`) 
- Automatické volání 
- mohou mít parametry
- většinou je konstruktor public
	- jsou zde ale i výjimky jako třeba Singleton, kde konstruktor nesmí být veřejný
- mohou volat konstruktor rodičovské třídy
- Máme 2 druhy konstruktorů 

	- #### Přetížené konstruktory
		- znamená že v jedné třídě můžeme mít více konstruktorů se stejným názvem, ale různou funkčností.
			- Umožnuje vytvářet objekty různými způsoby, podle toho jaká data máme k dispozici.
		- pravidlo pro počet konstruktorů - ideální počet konstruktorů je stejný jako počet atributů + (1 bezparametrický)
		- Dává nám možnost svobody kdy můžeme vytvořit `Osobu` se jménem,  nebo `Osobu` se jménem i věkem, podle toho, jaký konstruktor voláme
  
	- #### Parametrický a bezparametrický konstruktor
		- Bezparametrický konstruktor
			- nemá žádné parametry
			- Vytvoří objekt s pevně danými výchozími hodnotami
			- každý objekt jím vytvořený bude mít při startu stejné atributy
			- **Výchozí stav**: Pokud definujeme `Obdelnik`, bezparametrický konstruktor může nastavit pozici na `[0,0]` a rozměry na `[10,10]`.
			- **Flexibilita**: Pokud chceme později hodnoty změnit, musíme k tomu použít setter settery.
		- Parametrický konstruktor
			- při vytváření objektu rovnou předá konkrétní data, kterými se atributy rovnou inicializují.
			- při psaní parametrického konstruktoru se používá `this`. To slouží k odlišení parametrů metody od atributů třídy, pokud se jmenují stejně.
			- *Příklad* - `this.barva = barva;` říká: "Vezmi atribut `barva` tohoto objektu a přiřaď mu hodnotu, kterou jsem dostal v parametru `barva`
### Rozdíl mezi konstruktorem a metodou

Je důležité si neplést konstruktor s běžnou metodou. Metoda má návratový typ (např. int, `string` nebo void), zatímco konstruktor nemá žádný. Metoda se volá na již existujícím objektu, aby provedla nějakou akci (např. `vypoctiObsah()`), zatímco konstruktor se volá pouze jednou při vzniku objektu, aby ho "přivedl k životu" a nastavil jeho počáteční stav. Pokud metoda nic nevrací, označujeme ji jako proceduru a používáme klíčové slovo void. Pokud metoda vrací hodnotu, je to funkce a musí obsahovat příkaz `return`.

### Srovnání přístupů k inicializaci

|Typ inicializace|Výhoda|Nevýhoda|
|---|---|---|
|**Bezparametrický**|Jednoduchost, standardizace|Nutnost následného volání setterů|
|**Parametrický**|Okamžitá platná data|Vyšší nároky na správné pořadí parametrů|
|**Vlastnosti (Properties)**|Čitelnost, validace při zápisu|Objekt může být dočasně v neplatném stavu|
