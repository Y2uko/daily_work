# OOP

- object oriented programming
- populární programovací paradigma, které organizuje návrh softwaru kolem **dat (objektů)**, nikoliv kolem funkcí a logiky
- základní stavební kámen OOP (`class` a `object`)
- 4 hlavní pilíře OOP
	- **Zapouzdření** - Skrývá vnitřní stav a implementační detaily objektu před okolním světem
	- **Dědičnost** - Umožňuje vytvářet nové třídy na základě již existujících tříd
	- **Polymorfismus** -Schopnost objektů různých tříd reagovat odlišně na stejnou metodu
	- **Abstrakce** - Slouží k vyčlenění podstatných vlastností objektu a potlačení těch nepodstatných.
- Proč se používá ?
	- OOP se výborně hodí pro rozsáhlé softwarové projekty, jelikož zlepšuje udržovatelnost kódu, usnadňuje týmovou spolupráci a umožňuje snadněji modelovat reálné problémy
- Mezi nejznámější objektově orientované jazyky patří:
	- Java, C#, C++, Python nebo PHP

## Třída a Objekt
- v OOP je třída abstraktním vzorem (šablonou) a objekt její konkrétní instancí
	- **Třída**: Definuje vlastnosti (data) a chování (funkce). Je to jako stavební plán domu.
	- **Objekt**: Představuje vytvořenou entitu v paměti, která má tyto vlastnosti vyplněné a chování aktivní. Je to samotný postavený dům.
- ==klíčové stavební kameny==
	- Atribut - datové proměnné třídy (jméno, věk, barva)
	- metody - definují chování a manipulují s atributy
		- Konstruktor - Speciální metoda, která se volá při vytvoření nového objektu a inicializuje jeho počáteční stav
### Objekt 
- objekt je instance třídy
- ==konkrétní realizace třídy== 
	- Třída `Auto` --> Objekt `mojeAuto` (červené, Porsche, 4 kola)
- vzniká pomocí operátoru `new`, který zavolá konstruktor
	- **konstruktor** = Speciální metoda třídy, která se automaticky spustí při vytváření nové instance objektu a slouží k jeho inicializaci.
- **objekt** obsahuje:
	- Atributy (data o objektu) 
		- *Příklad* - `barva`, `jmeno`, `znacka`, `rychlost` atd...
	- metody (chování)
		- metody pracují s daty, objektu
		- *Příklad* - `nastartuj()`, `pridej_plyn()`

### Třída
- Základní šablona, podle které vznikají jednotlivé objekty
	- taková definice vnější struktury a rozhraní objektu
- složky tříd:
	- datové položky       
	- vlastnosti                 - `properties`
	- metody                     - `methods`
	- události                    - `events`
- z jedné třídy může vzniknout libovolný počet objektů
- definuje vlastnosti, které bude mít každý objekt vzniklý z této třídy
- slouží k organizaci kódu do logických celků
- **Zapouzdření** (Encapsulation): 
	- Třída umožňuje skrýt vnitřní složitost. 
	- Uživatel objektu ví, jakou metodu zavolat ale nemusí vědět, jak přesně je vnitřně naprogramované.
- *Ukázka Třídy*
``` C#
class Kniha
{
    // Atributy třídy
    public string Nazev;
    public string Autor;

    // Konstruktor - nastaví vlastnosti při vytvoření
    public Kniha(string nazev, string autor)
    {
        this.Nazev = nazev;
        this.Autor = autor;
    }

    // Metoda - definuje chování
    public void Popis()
    {
        Console.WriteLine($"Kniha: {Nazev}, Autor: {Autor}");
    }
}

// Vytvoření instance třídy (musí mít Nazev a Autora, protože to definovala třída)
Kniha mojeKniha = new Kniha("Zaklínač", "Andrzej Sapkowski");

// Volání metody objektu vypíše nám Název knihy a Jméno autora
mojeKniha.Popis();
```

## 4 Pilíře OOP

**Zapouzdření** (obalení)
	- Vyjadřuje schopnost objektu spojit v jeden celek data a metody
	- ukrytí uvnitř struktury objektu
	- Nemůžeme manipulovat přímo s atributy objektu, ale pouze pomocí operací z veřejného rozhraní objektu
	- Zamezuje nechtěným změnám či chybám stavu objektu
	- *Modularita* – každý objekt lze udržovat a spravovat nezávisle na jiném objektu, aniž by to nějak ovlivnilo celkovou funkčnost programu

**[[Dědičnost]]**
	- ==Umožňuje vytvářet nové objekty (**potomky**) již existujících objektů (**předků**), přebírat od nich datové položky a metody a může je modifikovat či upřesňovat.==
	- usnadňuje znovu použitelnost kódu a zpřehledňuje strukturu
	- **potomek** může využít konstruktor rodiče pomocí klíčového slova `base()`
	- *příklad*:
		- Máme třídu `Osoba`, ze které dědí `Žák`.
		- `Žák` má vše, co `Osoba`, ale přidává si vlastní specifické atributy (např. `trida` nebo `prumerZnamek`)

**Polymorfismus** (mnohotvárnost)
	- vlastnost OOP, která umožňuje pojmenovat metodu jedním jménem a tato metoda může být společná pro různé objekty ve stromové hierarchii
	*- Příklad* 
		- když ve třídě vytvořím metodu `počítej`, se 2 parametry
		- můžeme se stejným názvem vytvořit metodu znovu akorát se 3 parametry a pak 4 parametry (a tak dále a tak dále)

## skládání a delegování 

#### Skládání (Kompozice)
- vztah - „má část“ (např. škola má budovy, lidé mají srdce)
- technika, kdy vytváříme složitější objekty z objektů jednodušších.
```
1  //například 
2  bod1 = new Bod(0,5);
3  Bod bod2 = new Bod(3,3);
4
5  Usecka usecka1 = new Usecka(bod1, bod2);
```


#### delegování 
- v objektově orientovaném programování (OOP) je návrhový princip, při kterém objekt nepřenáší odpovědnost za určitou úlohu sám, ale **předá (deleguje) ji jinému objektu**, který je pro ni lépe vybaven
- *Příklad*
	1. Zavoláte metodu `auto.nastartuj()`. Třída `Auto` uvnitř této metody nezačne složitě popisovat vstřikování paliva. Pouze zavolá `motor.zapni()`. Práci tedy deleguje na motor.
	2. Třída `Úsečka` není definována jen souřadnicemi, ale skládá se ze dvou objektů třídy `Bod`. `Bod` má své `x` a `y` (definované jako Getter a setter), a `Úsečka` je pak využívá jako své součásti.


# Typické otázky u maturity

1. **Jaký je rozdíl mezi třídou a objektem?** Třída je šablona (kód) definující vlastnosti, objekt je konkrétní instance této třídy vytvořená v paměti pomocí new.
2. **K čemu slouží konstruktor a kolik jich může být?** Konstruktor inicializuje objekt a přiřazuje hodnoty atributům. Můžeme jich mít tolik, kolik je atributů + 1 (bezparametrický).
3. **Co je to zapouzdření a proč se používá?** Je to skrývání vnitřní struktury objektu. Zamezuje přímé manipulaci s daty, čímž chrání objekt před nechtěnými změnami a chybami.
4. **Jaký je rozdíl mezi procedurou a funkcí?** Procedura (void) pouze vykoná kód, funkce vrací hodnotu, kterou lze dále zpracovat nebo přiřadit do proměnné.
5. **Co znamená skládání (kompozice) v OOP?** Je to způsob tvorby objektů, kdy jeden objekt obsahuje jako své součásti objekty jiné (např. auto obsahuje motor, kola, volant).
