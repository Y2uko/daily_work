==Co je IP adresace (Internet Protocol address) ?==
- unikátní číselný identifikátor zařízení v počítačové síti
- umožnuje identifikovat zdroje a cíle komunikace
- Jedná se o logickou adresu, která je v rámci síťové vrstvy **OSI model** úzce vázána na `masku sítě` (určuje segment sítě) a `MAC adresu` (fyzická adresa síťového rozhraní)
	- **MASKA sítě** 
		-  32bitové číslo v protokolu IPv4, které určuje, která část IP adresy patří do sítě (podsítě) a která část identifikuje konkrétní zařízení (hostitele)
	- **MAC adresa** 
		- ==unikátní fyzický identifikátor síťového rozhraní== (např. Wi-Fi karty, Ethernet portu), který mu přiděluje výrobce
		- Skládá se ze 48 bitů, obvykle zapsaných jako 12 hexadecimálních znaků (např. `00:1A:2B:3C:4D:5E`)
		- Slouží k jednoznačné identifikaci zařízení v lokální síti.
-  Z pohledu síťového adaptéru je IP adresa logickým doplňkem fyzické adresy, přičemž routery využívají **NetID** *(Část IP adresy identifikující síť. Určena maskou sítě — bity odpovídající jedničkám v masce.)* k určení cílové sítě, do které mají být data směrována
- Pro zajištění bezpečnosti a správy sítě se dnes využívají dva hlavní standardy: **IPv4** a **IPv6**
	- IPv4 - ==Internet Protocol version 4==. Protokol využívající 32bitové adresy, který je stále dominantní, ale trpí nedostatkem volných adres.
	- IPv6 - ==Internet Protocol version 6.== Nástupce IPv4 využívající 128bitové adresy, který řeší vyčerpání adresního prostoru a přináší nativní podporu pro bezpečnostní prvky jako IPsec.

## Formát a soustavy

- **Desítková soustava:** Pro lepší čitelnost lidmi se `IPv4` zapisuje jako čtyři oktety oddělené tečkami (např. 192.168.0.1).
- **Dvojková (binární) soustava:** Síťová zařízení pracují pouze s nulami a jedničkami. Každý oktet (0–255) odpovídá 8 bitům (např. 192 = 11000000).
- **Hexadecimální soustava:** Používá se primárně u `IPv6`, kde je adresa zapsána jako osm skupin čtyř hexadecimálních číslic oddělených dvojtečkami (např. 2001:0db8:85a3:0000:0000:8a2e:0370:7334).

# Struktura IP adresy (HostID a NetID)

IP adresa se dělí na dvě části, jejichž hranici určuje **Maska sítě**

- NET/HOST ID
		NET  |  HOST
		10      |  10.10.10.10
		255    |  0.0.0	
      
	- **NetID** - 
		- Identifikuje konkrétní síť (podobné jako název ulice). Všechna zařízení v jedné lokální síti musí mít shodné NetID. 
		- Část IP adresy, která určuje, do jaké sítě zařízení patří

	- **HostID** - 
		- Identifikuje konkrétní zařízení v rámci dané sítě (podobné jako číslo popisné)
		- Unikátně identifikuje konkrétního hostitele.

- **Subnetting** - Proces dělení jedné velké sítě na menší logické celky (podsítě), což zvyšuje bezpečnost a snižuje provozní zátěž (broadcast doménu).


# Maska sítě a výpočty

Maska sítě je ==32bitové číslo==, které definuje, která část IP adresy patří síti a která konkrétnímu zařízení.

- **Binární zápis:** Maska se skládá z řady jedniček (NetID) následovaných řadou nul (HostID). 
	- Příklad: 255.255.255.0 je binárně 11111111.11111111.11111111.00000000.
- **Výpočet podsítí:** Počet podsítí se vypočítá jako:
	- $2^n - 2$ 
- (kde $n$ je počet nul v masce, které byly změněny na jedničky pro potřeby podsítí).  Takže pokud máme masku sítě od 32 odebereme výsledek **n**
- **Počet klientů:** Počet využitelných adres pro koncová zařízení se vypočítá jako:
	- $2^n - 2$ 
	- (kde $n$ je počet nul v masce; odečítají se 2 adresy: `adresa sítě` a `broadcastová adresa`).
- **Prefix:** Zjednodušený zápis masky vyjadřující počet jedniček v binárním zápisu. Zapisuje se za lomítko (např. 192.168.0.1/24 znamená masku 255.255.255.0).
- **VLSM:** 
	- Variable Length Subnet Mask. Metoda umožňující používat různé masky podsítí v rámci jedné sítě, čímž se efektivněji využívá adresní prostor.

- **Třídy:**
- Výpočty tříd:
		A	0	/8	2na24
		B	10	/16	2na16
		C	110	/24 	2na8


### Přidělování IP adres
3 typy přidělování IP adres

- **Staticky:** 
	- Administrátor nastaví IP adresu, masku a bránu ručně přímo v konfiguraci síťového rozhraní zařízení v desítkové soustavě.

- **Dynamicky (DHCP):** 
	- Protokol DHCP (Dynamic Host Configuration Protocol) automaticky přidělí zařízení IP adresu z definovaného rozsahu. Proces probíhá ve čtyřech krocích:
		1. DHCPDISCOVER (klient hledá server), 
		2. DHCPOFFER (nabídka serveru), 
		3. DHCPREQUEST (požadavek klienta) 
		4. DHCPACK (potvrzení serverem).
	- Po obdržení může klient IP používat. Klient musí obnovit svou IP adresu před uběhnutím lhůty, aby ji mohl nadále používat 
	
	- **APIPA:** 
		- (Automatic Private IP Addressing) 
		- APIPA je mechanismus, kdy si operační systém přidělí adresu sám z rozsahu 169.254.x.x , pokud se mu nepodaří získat adresu z DHCP serveru.

### Služby a DNS

**DNS (Domain Name System):**
- Distribuovaný systém, který překládá doménová jména (např. seznam.cz) na IP adresy srozumitelné pro počítače.
- **Typy DNS serverů:**
	- **Autoritativní:** Ukládá záznamy pro konkrétní spravovanou doménu (konkrétní síť).
	- **rekurzivní (Cache):** Ukládá dočasně záznamy, které klient potřebuje přeložit, pro zrychlení přístupu.
	- **Root name:** Nejvyšší úroveň hierarchie (celkem 13 serverů označených A–M), které odkazují na servery top-level domén.
		- Překládá doménové jméno (např seznam.cz) na IP adresu, čitelnou pro počítač 
		- ==root servery:==
			- spadají do top level domain
			- názvy root serveru A až M
			- existují domény 1, 2 a 3 řádu
				1.řád : **cz** (národní a korporátní)
				2.řád : **seznam**.cz
				3.řád : sub domény - **quarts**.seznam.cz

### Viditelnost IP adres

- **Privátní IP adresy:** Jsou určeny pro vnitřní sítě (LAN). Jsou v internetu neviditelné a nejedinečné (každá firma může mít stejný rozsah 192.168.x.x). Pro komunikaci do internetu využívají NAT

- **Veřejné IP adresy:** Jsou unikátní v rámci celého internetu a přiděluje je poskytovatel připojení ISP (**Internet Service Provider**).
	- například: Vodafone, O2, T-Mobile atd.


## Třídy IP adres

- Historické rozdělení rozsahu `IPv4` adres (dnes nahrazeno beztřídním směrováním **CIDR**):
	- CIDR *(Classless Inter-Domain Routing)* Metoda přidělování IP adres, která nahradila třídní systém a umožňuje flexibilnější definici velikosti sítí pomocí prefixů.

| Třída | První bity | Rozsah IP       | Maska           | Prefix |
| ----- | ---------- | --------------- | --------------- | ------ |
| A     | 0          | 0 – 127.x.x.x   | 255.0.0.0       | /8     |
| B     | 10         | 128 – 191.x.x.x | 255.255.0.0     | /16    |
| C     | 110        | 192 – 223.0.0.0 | 255.255.255.0   | /24    |
| D     | 1110       | 224 – 239.0.0.0 | 255.255.255.255 | /32    |
| E     | 11110      | 240 – 255.0.0.0 | --              | --     |
*Poznámka:* Třída D je vyhrazena pro `multicast` (skupinové vysílání), třída E je experimentální.
	 **Multicast** - efektivní metoda síťové komunikace, při které jeden odesílatel posílá data skupině více příjemců najednou

### Klíčové pojmy

- **IPv4:** Čtvrtá verze internetového protokolu, využívající 32bitové adresy; nejrozšířenější protokol pro adresaci v síti.
- **MAC adresa:** Fyzická adresa vypálená výrobcem do síťové karty; slouží pro komunikaci v rámci lokální sítě (linková vrstva).
- **Oktet:** Skupina 8 bitů; `IPv4` adresa se skládá ze 4 oktetů.
- **Broadcast:** Zpráva odeslaná všem zařízením v dané síti; cílová IP adresa v tomto případě končí na 255.
- **Gateway (Brána):** Zařízení (obvykle router), které umožňuje komunikaci mezi různými sítěmi (např. mezi vaší LAN a internetem).
- **Multicast:** Metoda síťové komunikace, při které je jeden datový paket odeslán skupině příjemců současně.
- **Loopback adresa:** Speciální adresa 127.0.0.1, která slouží k testování síťového rozhraní vlastního počítače (tzv. localhost).
