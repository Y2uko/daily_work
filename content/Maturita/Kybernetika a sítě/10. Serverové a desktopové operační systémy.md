
==Operační systém OS je systémový software, který:==
- zprostředkovává **komunikaci mezi hardwarem a softwarem**
- spravuje **procesor, paměť, diskové úložiště a zařízení**
- poskytuje programům a uživatelům **služby pro běh aplikací**  
    Operační systém funguje jako **“mozek” počítače** – bez něj by počítač prakticky nefungoval. 
- Použití OS výrazně usnadňuje vývoj softwaru, neboť poskytuje standardizované rozhraní pro programátory.
- Moderní OS zajišťují abstrakci hardwaru, správu paměti a bezpečnostní izolaci procesů

**Hlavní funkce** 
- Operační systém plní tři základní funkce: ovládání počítače, abstrakce hardware a správa prostředků:
- Řízení zpracovávaných úloh
- Řídí a spravuje přístup k systémovým prostředkům
- Řízení a obsluhu vstupních/výstupních zařízení:
- Připojení k počítačové síti (LAN, WAN)
- Tiskárny
- Správu paměti
- Správu disků a údržbu systému souborů
- Komunikaci s uživatelem a obsluhu jeho požadavků
- Spouštění programů

# Holý počítač (Bare-metal)

Stav počítače, který obsahuje pouze fyzický hardware a firmware ([[BIOS]]) nebo [[UEFI]]. V tomto stavu počítač není schopen vykonávat uživatelské úlohy, dokud není nainstalován operační systém, který hardware inicializuje a zpřístupní.

### Součásti operačního systému

1. **Kernel (Jádro):** Srdce OS, které má přímý přístup k hardwaru (procesor, paměť, disky). Řídí zdroje a zajišťuje komunikaci mezi hardwarem a aplikacemi.
2. **Rozhraní:**

- **CLI** (`Command Line Interface`): Textové rozhraní (příkazová řádka), např. `CMD` nebo [[Bash]]. Umožňuje přímou správu systému pomocí příkazů.
- **GUI** (`Graphical User Interface`): Grafické rozhraní (okna, ikony, myš), např. prostředí Windows nebo [[GNOME]]. Historicky vychází z konceptu [[WIMP]].

4. **Systémové aplikace:** Předinstalované nástroje nezbytné pro chod systému (např. správce souborů, textový editor, ovládací panely).
5. **Aplikace třetích stran:** Programy instalované uživatelem pro konkrétní účely (např. webový prohlížeč, kancelářský balík, archivační nástroje).

### Architektura a Multitasking

- **Architektura (32-bit vs. 64-bit):** 32-bit systémy jsou dnes překonané (omezení adresace paměti RAM na 4 GB). 64-bitové systémy umožňují využít násobně vyšší kapacitu paměti a jsou standardem pro moderní hardware.
- **Multitasking:** Schopnost systému spouštět a spravovat více procesů (úloh) současně. Aktivní aplikace má obvykle vyšší prioritu přidělení procesorového času.
- **Hyper-threading:** Technologie procesoru, která umožňuje jednomu fyzickému jádru simulovat dvě logická jádra. Operační systém díky tomu může paralelizovat výpočty efektivněji.
- **Virtualizace:** Technologie umožňující běh více virtuálních strojů na jednom fyzickém hardwaru pomocí Hypervizor.

### Licenční modely

- **GNU-GPL:** Svobodná licence (např. Linux), která umožňuje kód studovat, upravovat a šířit, pokud je zachována otevřenost.
- **EULA** (`End-User License Agreement`): Licenční smlouva s koncovým uživatelem (Windows, macOS), která určuje, jakým způsobem smí uživatel software používat; kód je uzavřený.
- **Open-Source:** Software s otevřeným zdrojovým kódem, který může kdokoli zdarma používat a upravovat (např. ReactOS).

# Struktura souborového systému

### Linux (Stromová struktura začínající kořenem)

- `/bin`: Základní spustitelné soubory pro všechny uživatele (ekvivalent `C:\Windows\System`).
- `/boot`: Soubory zavaděče systému (**GRUB**]), kernel a konfigurační soubory pro start OS.
- `/dev`: Obsahuje soubory reprezentující fyzická zařízení (disky, porty, terminály).
- `/etc`: Globální konfigurační soubory pro instalovaný software.
- `/home`: Domovské adresáře uživatelů (obdoba `C:\Users`).
- `/lib`: Sdílené systémové knihovny potřebné pro běh programů.
- `/mnt` / `/media`: Místa pro připojení externích úložišť (USB, disky, CD).
- `/proc`: Virtuální systémový adresář obsahující informace o stavu procesů a paměti (jako `Správce úloh`).
- `/root`: Domovský adresář superuživatele (správce systému).
- `/tmp`: Dočasné soubory, které se často po restartu mažou.
- `/usr`: Obsahuje instalované aplikace, knihovny a uživatelská data.
- `/var`: Proměnné soubory, které se mění za běhu (např. logy nebo data webového serveru v `/var/www`).

### Windows (Jednotková struktura)

- `C:\`, `D:\`: Kořenové adresáře diskových oddílů.
- `Program Files`: Instalace 64-bitových programů.
- `Program Files (x86)`: Instalace 32-bitových programů (oddělené z bezpečnostních a kompatibilních důvodů).
- `Users`: Profily uživatelů.
- `ProgramData`: Skrytá složka pro konfigurace aplikací sdílené všemi uživateli.
- `Windows`: Samotný operační systém, ovladače a systémové nástroje.
- Registry.

# Desktopové vs. Serverové OS

|Vlastnost|Desktopový OS|Serverový OS|
|---|---|---|
|**Hlavní cíl**|Uživatelská přívětivost|Stabilita, výkon, správa sítě|
|**Správa**|Lokální uživatel|Centrální správa (AD, role)|
|**Typické role**|Kancelář, multimédia|DHCP, DNS, File, Mail|
|**Příklad**|Windows 11, macOS, Ubuntu|Windows Server, Linux Server|

### Desktopové OS 
Jsou určeny pro **běžné uživatele** a osobní počítače:
- mají **grafické uživatelské rozhraní (GUI)**
- Určeny pro lokální koncové uživatele. Zaměřují se na grafické rozhraní, multimédia, kancelářskou práci a základní síťové připojení. Windows využívá jádro NT, zatímco macOS staví na systému Darwin.

- **Příklady:**
- Microsoft Windows (10, 11)
- macOS (Apple)
- Linuxové distribuce (Ubuntu, Linux Mint)

### Serverové OS 
Speciální verze OS optimalizované pro vysoký výkon, bezpečnost a správu sítě.

- Serverový OS je takový operační systém, který je **optimalizován pro běh služeb pro ostatní počítače** (klient/server architektura). 
- **Server** je počítač, který poskytuje služby klientům (např. jiným počítačům v síti). 

- **Role serveru:**
	- **DHCP:** Automatické přiřazování IP adres zařízením v síti.
	- **DNS:** Překlad doménových jmen (např. www.google.com) na IP adresy.
	- **Active Directory (AD):** Služba pro správu uživatelů, skupin a oprávnění v podnikové síti.
	- **Print Server:** Centralizovaná správa síťových tiskáren.
	- **File Server:** Centrální úložiště dat s řízeným přístupem.
	- **Mail Server:** Správa a doručování e-mailů.

**Poznámka k bezpečnosti:** Serverová řešení jsou bezpečnější, protože umožňují centrální správu oprávnění a pravidelné zálohování, na rozdíl od lokálního úložiště na desktopu, které je zranitelnější vůči útokům či ztrátě dat. Serverové systémy často využívají RAID.

- ==Mezi známé serverové OS patří:== 
	- **Windows Server** (různé verze: 2000, 2003, 2008, 2012, 2016…)
	- **Linux Server** (např. Ubuntu Server, Red Hat Enterprise Linux)
	- **Solaris**
	- **FreeBSD**
	- **Mac OS X Server**

- **Typické serverové služby**

	- **_Databázový server_**
		- Ukládá a zpřístupňuje databáze klientům (MySQL, Oracle, PostgreSQL). 

	- **_Souborový server_**
		- Sdílí soubory mezi uživateli a usnadňuje zálohování dat. 

	- **_Webový server_**
		- Hostuje webové stránky a odpovídá na HTTP požadavky. 

	- **_Mail server_**
		- Zpracovává e-maily pomocí protokolů:
			- SMTP server – přenos pošty mezi servery
			- POP3/IMAP – přístup klienta k poště 

	- **_Tiskový server_**
		- Spravuje frontu tiskových úloh a připojené tiskárny. 

	- **_Proxy server_**
		- Zprostředkovává připojení klientů a tím zvyšuje bezpečnost a výkon. 

	- **_DNS server_**
		- Překládá doménová jména na IP adresy (např. seznam.cz → 77.77.77.77). 

### Typy serverů (podle funkce)

- **Webový server:** Poskytuje webové stránky (HTML, obrázky) prohlížečům (např. Apache).
- **Databázový server:** Ukládá data a poskytuje je aplikacím pro čtení a zápis.
- **Blade server:** Modulární servery šetřící místo v racku (vysoká hustota výkonu).

## Klíčové pojmy

- **BIOS/UEFI:** Firmware zajišťující start hardwaru před spuštěním OS.
- **Kernel:** Jádro OS komunikující přímo s hardwarem.
- **[[Multitasking]]:** Schopnost systému běžet více úloh najednou.
- **Active Directory:** Databázová služba pro správu identit v síti.
- **DHCP:** Protokol pro automatickou distribuci IP adres.
- **DNS:** Systém doménových jmen, "telefonní seznam" internetu.
- **Root:** Superuživatel v Linuxu s nejvyššími právy.
- **Client-Server:** Model, kde jeden výkonný počítač (server) poskytuje služby mnoha koncovým stanicím (klientům).
- [[SSH]].
